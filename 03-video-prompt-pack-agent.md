# 03-video-prompt-pack-agent.md

Read the brand kit from:

brand-kit.md

Your task is not to generate video.
Your task is to create a standalone video prompt pack that will later be used in an external video generation tool.

Create a file called:

video-prompts.md

Inside video-prompts.md, create a structured cinematic website video prompt pack.

Assume that these files may later exist in the same folder and may be used as references:

- brand-hero-reference.png
- brand-material-reference.png
- brand-workspace-reference.png

Create:

1. One master prompt for the main landing page background video
2. Two alternate prompt variations
3. One fallback prompt for a simpler motion version
4. One technical adaptation note for scroll-driven websites

For each video prompt, include:

- Prompt title
- Objective
- Use case in the website
- Main prompt
- Negative prompt
- Continuity with reference images
- Product / service consistency notes
- Motion direction
- Camera movement
- Lighting direction
- Materials / detail emphasis
- Environment / atmosphere guidance
- Composition guidance for headline and CTA overlays
- Duration recommendation
- Aspect ratio recommendation
- Render quality recommendation
- File naming recommendation

Global rules:
- The video must be suitable for a scroll-driven website, not just a standalone ad clip.
- Motion must be slow, stable, elegant, and text-friendly.
- Keep enough negative space for overlays.
- No people unless explicitly required by the brand kit.
- No real logos.
- No third-party marks.
- No readable text inside the video.
- No chaotic movement.
- No cluttered background.
- Keep the visual language aligned with the brand manual.

Suggested filename:
- brand-scroll-background.mp4
