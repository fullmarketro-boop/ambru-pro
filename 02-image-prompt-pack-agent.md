# 02-image-prompt-pack-agent.md

Read the brand kit from:

brand-kit.md

Your task is not to generate images.
Your task is to create a standalone image prompt pack that will later be used in an external image generation tool.

Create a file called:

image-prompts.md

Inside image-prompts.md, create a structured image generation pack based on the brand kit.

Create prompts for these visual directions:

1. Hero Reference Image
2. Material / Detail Reference Image
3. Environment / Lifestyle Reference Image
4. Optional Secondary Composition Image
5. Optional Wide Banner / Editorial Image

For each image prompt, include:

- Prompt title
- Objective
- Use case in the website
- Main prompt
- Negative prompt
- Brand consistency notes
- Subject consistency notes
- Composition notes
- Lighting notes
- Materials and texture notes
- Color usage notes
- Mood notes
- Camera / lens notes if relevant
- Aspect ratio recommendation
- Quality / realism recommendation
- File naming recommendation

Global rules:
- Use the brand kit as the single source of truth.
- Keep the product or service representation consistent across all prompts.
- Keep the style premium, polished, controlled, and aligned with the brand identity.
- No real brand logos.
- No third-party marks.
- No baked-in text.
- No random design drift between prompts.
- Write prompts so they can be copied directly into another image generation program.
- Make them suitable for commercial website use.

Suggested filenames:
- brand-hero-reference.png
- brand-material-reference.png
- brand-workspace-reference.png
- brand-secondary-reference.png
- brand-banner-reference.png
